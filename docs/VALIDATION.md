# التحقق وحدود الاختبار — 1.3.2

## تحقق الإصدار المحلي

- جرد الترجمة: **2,382** مدخلًا، دون مفاتيح ناقصة أو إضافية أو مكررة، ودون أحرف عربية مفقودة من الخط.
- مصدر الترجمة والخطوط وملفات الترجمة المترجمة ثنائيًا لم تتغير عن الإصدار السابق. التوقيع الجديد استثناء محدد في خاصية زر واحد فقط، وليس تعديلًا لترجمة مشتركة.
- فحص بنية PAK: **127 ملفًا** للنسخة التدريجية و**135 ملفًا** لنسخة التلاشي؛ فحص UnrealPak المحلي ناجح.
- فحوص الواجهات المحلية حفظت بيانات الدوال والحركات والارتباطات في التعديلات المحددة. هذه فحوص بنية، وليست دليلًا على كل حالات اللعب.
- **9 اختبارات للمثبّت** في مجلدات تجريبية منفصلة: أرقام إصدارات مختلفة، غياب ملف الإصدار، EXE غير معروف، النسخ الاحتياطي، التطبيق والإرجاع والتكرار والإزالة بعد تحديث اللعبة ورفض غياب ملف التشغيل.
- أُعيد بناء النسختين من المصدر المعدّ للنشر؛ طابقت بصماتهما ملفات PAK المعتمدة بايتًا ببايت. فحص GitHub لتصيير README أبقى حاويات RTL والصور الست وجدولي المقارنة والمساعدة.

## ما شوهد داخل اللعبة

اختُبرت اللعبة <bdi>1.01.03 / Steam build 13480</bdi> بملفات حفظ اختبار منفصلة:

| الحالة | النتيجة المرصودة |
| --- | --- |
| النسخة الكاملة، 1080p و4K | المخزون والمعدات والدليل وسجل الوحوش، حالات معدات مشغولة وفارغة، ونسبة إكمال 5.4% بأسفل اليسار. |
| النسخة الكاملة، 4K | زر التوقيع وفتح شاشة الشارة الأصلية، بيانات الحفظ بجانب عناوينها وبعيدًا عن العملات، وتبديل فئات المخزون. |
| PAK مع EXE أصلي، 720p | المتجر والأسماء والأسعار والأعداد والتمرير والعناصر غير المتاحة. شراء الأعشاب غيّر الكمية من 0 إلى 1 والعملات من 12 إلى 9. |
| PAK مع EXE أصلي، 720p | خيارات شراء/بيع/مغادرة، ورد تاجر عربي من سطرين. لا توجد عملية بيع مكتملة ضمن هذا الاختبار. |
| PAK النهائي، 720p | عناوين قائمة الإيقاف الظاهرة كاملة ومتمركزة في سطر واحد. |

الصور لقطات من نافذة اللعبة بوحدات العرض المنطقية؛ لا تمثل ملفات صور أصلية بدقة 4K. صور المتجر تعرض نسخة التلاشي، وصور المخزون والدليل وسجل الوحوش تعرض النسخة الكاملة. التعديل الأخير بعد بقية اللقطات اقتصر على قائمة الإيقاف.

## ما لم يُثبت اختباره

لم تُستكمل مصفوفة كل نسب الشاشات <bdi>16:10 / 21:9 / 4:3</bdi>، ولا كل أسماء العناصر والأسعار والأعداد، ولا جميع حالات الترقية والبيع أو وحدات التحكم الفعلية. بعض الكتب والمشاهد ذات النص التدريجي متعدد الأسطر تحتاج اختبارًا خاصًا. قبول المثبّت لإصدارات أخرى لا يثبت توافق الواجهات مع ملفاتها.

فحوص ZIP والبصمات وقائمة محتويات PAK لهذا النشر موثقة في [بيان الإصدار](release-manifest.json). فحص الأسرار محلي قائم على الأنماط ومراجعة قائمة الملفات؛ لا يعد شهادة أمنية أو فحص مضاد فيروسات.
