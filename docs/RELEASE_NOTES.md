# التعريب العربي — 1.3.2

**MIZO & ABDULAZIZ** · تحميل مجاني

تحسين ترتيب الأيقونات والأسماء في المتجر والمخزون والمعدات، وإصلاح موضع نسبة الإكمال وقياس عناوين قائمة الإيقاف، مع تحسين تباعد أسطر الوصف. الترجمة الـ2,382 لم تتغير عن الإصدار السابق.

المثبّت يقبل أرقام الإصدارات المختلفة ويختار نسخة PAK تلقائيًا عند عدم توافق EXE. الظهور التدريجي من اليمين يظل خيارًا إضافيًا لملف التشغيل المعروف فقط. اختبار اللعبة الفعلي كان على <bdi>1.01.03</bdi>؛ لا ندّعي توافق كل تحديث مستقبلي.

- **Full-Installer.zip:** فك الضغط ثم شغّل <bdi>install.bat</bdi> واتبع الخيارات.
- **Manual-PAK.zip:** انسخ <bdi>zz_QueensDomain_Arabic_P.pak</bdi> إلى <bdi>QueensDomain/Content/Paks</bdi>. الحوار كامل مع تلاشي، دون تعديل EXE.
- **SHA256SUMS.txt:** بصمات الحزمتين للتحقق من سلامة التنزيل.

اختر حزمة واحدة. لا تحتاج ملفات Source code التي يولّدها GitHub تلقائيًا للعب؛ فهي مصدر المشروع وليست حزمة تثبيت.
